- Frontend: React + Vite + TypeScript + Tailwind CSS

- PDF: Puppeteer to render server-generated HTML → PDF; optional DOCX via `docx` npm
- Content: TypeScript/JSON files in `/src/content`
- Deploy target: Replit (use Secrets for env)

## SOW Generator (/scope)
### Form steps (client-facing)
1) **Contact**: name, email, org, role, phone
2) **Project Basics**: service types (multi), project title, goals (short), audience, desired outcomes
3) **Timeline & Budget**: preset options (2/4/8/12 weeks), budget band (e.g., <$5k, $5–15k, $15–40k, $40k+)
4) **Tech Context**: tools of interest (AI/AR/3D/IoT/Shopify), integrations, data/security needs
5) **Deliverables**: checklist auto-suggested by service + custom entries
6) **Success Metrics**: checkboxes + free text (e.g., prototype delivered, AR preview live, GPS dashboard online, storefront launched)
7) **Legal/Compliance**: IP ownership preference, confidentiality, accessibility (WCAG), data handling
8) **Review & Generate**: preview, then “Generate SOW”

### Server: OpenAI-driven SOW (Express)
- Endpoint: `POST /api/sow`
- Use OpenAI Responses API with JSON Schema to get structured SOW:
  - Fields: projectTitle, client, date, summary, objectives[], scope[], deliverables[], timeline[{week,milestone}], successMetrics[], assumptions[], outOfScope[], pricingModel, pricingNotes, legal{ipOwnership,confidentiality,accessibility,dataSecurity}
- Render returned JSON to HTML, then puppeteer to **PDF**; also return raw JSON and HTML.
- Endpoint: `POST /api/sow/pdf` to return a file download (application/pdf).

### Example SOW JSON schema (strict)
- Implement a `SOW_SCHEMA` (as in server code) and pass via `response_format: { type: "json_schema", json_schema: SOW_SCHEMA }`.
